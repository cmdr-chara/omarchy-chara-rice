# Chara Crimson artwork sources

The public theme contains no third-party artwork file.

## Animated eyes

- Scene: *Chara's eyes*, Workshop item 3450338231, uploader f1re.
- Source: https://steamcommunity.com/sharedfiles/filedetails/?id=3450338231
- The optional `chara-live-wallpaper.service` expects the user to already own
  or install the Wallpaper Engine asset. The service is disabled by default.

## Fastfetch

The public `chara-fastfetch` helper renders the included text soul by default.
Users may supply an image they own at
`~/.config/fastfetch/character-fullbody.png`; the rice does not bundle or
redistribute that image.

No generated Chara art or crossover art is included.
